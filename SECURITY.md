# Security Policy

## Supported Versions

Only the latest release of `alpaca-extfs` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or potential data loss issue in `alpaca-extfs`, please **do not** open a public issue.

Instead, please report it privately to the maintainer:

- **Email**: maxsonferovante@gmail.com
- **GitHub**: [@maxsonferovante](https://github.com/maxsonferovante)

Please include:
1. Description of the issue and potential impact.
2. Steps to reproduce the problem.
3. Affected versions and system configuration (macOS version, macFUSE version).

You will receive an acknowledgment within 48 hours, and progress updates until the issue is addressed.
